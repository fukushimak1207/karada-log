# からだログ

自宅でやる自重トレーニングの記録アプリ。**今日やる動画を1本だけ出して、やったことを記録する。**

スマホのブラウザで動くオフラインPWA。サーバーもアカウントも要らない。

## やること

1. 開くと**今日やる動画が2本**出る（1本目＝部位のローテ、2本目＝体幹）
2. **「○:○○ から再生」を押すとアプリの中で再生が始まる**（YouTube に飛ばない）。
   解説の長い動画は、運動が始まるところから再生される
3. 戻って「やった」を押す。2本終えたところで**まだできそうか**を答える
4. できそうなら、もう1本出る。何本でも続けられる

## 部位のまわし方

1本目は **下半身 → 上半身 → 背中 → 体幹** の4日サイクル。
**2本目は体幹**（1本目が体幹の日は、胸や腕など手薄なところ）。
**ストレッチは別タブ**（下記）。

腹筋を増やしたいという希望で2本立てにした。体幹が週1.8回から約5回に増える。
厚労省の「週2〜3日」は超えるので、腰や首に違和感が出たら2本目を減らす。

体で一番大きい下半身から始める。厚生労働省の「健康づくりのための身体活動・運動ガイド2023」は、
筋トレを週2〜3日、大きな筋群をまんべんなく鍛えることを勧めている。

**3日目はもともと「全身」だった**が、2026-11-05 に「背中」へ入れ替えた。
全身は1本で部位を広く扱うぶん1部位あたりが薄く、前後の日と中身がかぶっていた。
背中は自重では「引く」相手がいなくて手薄だったので、チューブが入ったこの枠に独立させた。
**全身の動画11本は消していない。** 設定の「今日の動画を変える」で部位に「全身」を選べば出る。

上半身の日は、胸 → 肩 → 腕と内部でも回る（背中は3日目に独立した）。同じところばかりにならないよう、
直近2回と同じ部位の動画は選ばれない。

> [!warning] 腹筋ローラーは2日に1回まで
> 腰を痛めやすいので、`sub` が「ローラー」の動画は中1日あけないと出ない。
> やさしいレベルのローラーは**フォームと安全な使い方の解説**で、
> 実践メニューはレベルが上がってから出る。立ちコロの動画は入れていない。

## 強度の上げ方

動画は部位ごとに「やさしい / ふつう / きつい」に分けてある。

- **決められた2本を終えたあと、追加の1本も実際にやった日**が2日続くと、1段きつくなる
  （「できそう」と答えただけでやらなかった日は数えない）
- 「ここまで」で記録すると据え置き（下がることはない）
- 判定に使うのは**その日の1本目の回答だけ**（2本目以降も数えると1日で何段も上がってしまう）

## 測る日の知らせ

設定で選んだ曜日にアプリを開くと、画面の上に「今日は測る日です」と出る。
**体重や体脂肪の数値はこのアプリに入れない。** 残るのは測った日付だけで、数値は Health Planet に入れる。

- 「測った」を押すとその日の分は消える。前回から10日以上空いたら曜日に関係なく出る
- 2027-01-18（見直しの日）が来たら、一度だけ別の知らせが出る

> [!note] 定時の通知は出せない
> Web アプリが自分で決まった時刻に鳴らす仕組み（Notification Triggers API）は
> Chrome で試験導入されたまま正式採用されていない。サーバーを持てば通知を送れるが、
> 月額0円の条件から外れる。**開いたときに画面へ出す**のが上限。

## 運動が始まるところから再生する

きんにくTV の動画は総尺15分で、実際に動くのは3〜5分。残りは解説なので、
**運動が始まる時刻を動画ごとに覚えておき、そこから再生する**。

- 7本は**自動で求めた**。自動生成字幕を見て、いちばん長い「`[音楽]` だけの区間」の
  先頭を実践の開始とみなす（実践中は話さないので字幕が `[音楽]` ばかりになる）。
  区間の長さがタイトルの「○分」と一致することで裏が取れる
- 残りは**使いながら埋める**。再生して運動が始まったところで
  「いまのところを開始位置にする」を押すと、次からそこで始まる（手入力は不要）

> [!note] 全部を自動では取れなかった
> 40本を続けて取りに行くと YouTube 側に弾かれる（`NoTranscriptFound` が返る）。
> 間隔を空ければ追加できる。判定の道具は scratchpad の `detectstart.py`。

## 全画面にすると横向きになる

全画面になったら横向きに固定する。[MDN](https://developer.mozilla.org/ja/docs/Web/API/ScreenOrientation/lock)に
「向きの固定はモバイル端末で、かつブラウザーが全画面表示になっているときのみ有効」とあるため、
**全画面が先、向きの固定が後**。対応していない端末では何も起きない（再生はそのまま続く）。

## 広告について

**消す仕組みは作らない。** 規約に反し、動画を作っている人の収入を止めることになる。
Premium は月額がかかるので0円の条件にも反する。

## 必要な道具

カードに「要るもの：ペットボトル」のように出る。**入っていない動画は、使ったときに
カードの「道具」から選んで覚えさせる**（次から出る）。

> [!note] 概要欄からは拾えなかった
> 40本の説明文を調べたが当てにならない。他の動画の宣伝文に「ダンベル」「椅子」が
> 紛れていて誤検出だらけになり、**実際にペットボトルが要る動画には何も書かれていなかった**。
> 字幕（話している中身）なら拾える見込みがあるので、後日あらためて調べる。

## やる種目

カードに「やる種目（7つ）」として並ぶ。**時間を押すと、再生中の動画がその種目まで飛ぶ。**
いまは7本の動画に入っている（脚・レッグランジ・腹筋・大胸筋・背筋・肩・二の腕）。
入っていない動画は今までどおり何も出ない。

> [!note] 種目名は動画のテロップから書き写した
> 概要欄にも字幕にも種目名は無く、画面に焼き込まれたテロップにしかない。
> 動画は20秒運動＋10秒休憩の30秒周期なので、運動開始位置が分かれば各種目の時刻は
> 計算で出る。時刻は±3秒ほどずれるので、**少し手前に着く**ようにしてある。
> 残りの動画は、運動開始位置が分かってから足す。

## ストレッチ

**別タブにしてある。記録しない**（連続日数にも、のべ本数にも入らない）。
ほぐしたいところは日によって違うので、自動で1本出すのをやめて一覧から選ぶ形にした。
部位（お尻・肩こり・肩甲骨・股関節・長座・腰）の順に並ぶ。

> [!note] 筋トレの記録と混ぜない
> 以前は3本目として毎日出していたが、ストレッチだけの日でも連続日数が伸びてしまい、
> 筋トレを続けられているかが読めなくなる。

## 合わない動画を外す

カードの下に2つボタンがある。

- **別のにする** … 同じ部位・レベルの別の動画に差し替える（今日の分だけ）
- **もう出さない** … その動画を以後出さない。設定の「動画リスト」で戻せる

**「やった」を押したあとのカードにも「もう出さない」がある。** やってみて初めて合わないと
分かることが多いため。押しても**記録は消えない**（記録は動画のIDを持っているだけで、
オン・オフとは別に保存されている）。すでに終わっているので、別の動画への差し替えもしない。

**タオルを使う2本は既定でオフにしてある**（本人がタオルを苦手なため）。
使いたくなったら設定の「動画リスト」でオンにする。

ローラーの「安全な使い方とフォーム」は**1回やったら出なくなる**（`once`）。
解説だけで回数が無く、繰り返し出ても練習にならないため。

## データ

**トレーニングの記録はこの端末のブラウザの中だけにある。** 外へは送らない。

> [!note] 送るのは「意見」だけ
> 画面右上の「意見」ボタンから送ったものだけが外に出る（本文と、そのとき開いていた画面の状態）。
> 送り先は非公開リポジトリの Issue で、合言葉を知っている人しか書き込めない。
> **体重・体脂肪・目標メモは送らない**（そもそもこのアプリが持っていない）。
> 意見を送らなければ、このアプリは通信しない（動画を開くときを除く）。

ブラウザのデータを消したり機種を変えると消えるので、設定画面から
ときどき JSON に書き出しておく。30日書き出していないと画面で知らせる。

## メニュー（処方型）

動画を流す形とは別に、**種目・回数・負荷を自分に合わせて出す**タブがある。2026-11-05 追加。

### チューブの負荷

5本の強さは **黄10 / 青15 / 赤20 / 緑25 / 黒40 ポンド**（ゴム本体の印字）。
ハンドルに複数本を掛けると足し算になり、**10〜100ポンドが5ポンドきざみ、最後に110ポンドの20段**。
同じ強さを作れる組が複数あるときは、本数の少ないほうを使う（付け替えが楽なため）。

⚠️ 印字のポンドは目安。**ゴムは伸びた距離で張力が変わる**ので、ダンベルの重さとは違う。
段を上げ下げする相対的な目盛りとして使う。

### 目標の上げ下げ

**8〜15回 × 3セット**（プランクなど秒で数えるものは 20〜60秒）。

1. 15回に届いた → 負荷を1段上げて、回数を8に戻す
2. 8回に届かなかった → 負荷を1段下げる
3. 目標に届いた → 目標を1つ増やす
4. 目標を大きく下回った（秒なら10秒、回数なら3回）→ 目標を実測まで下げる
5. 少しだけ届かなかった → そのまま据え置き

4がないと、測定で高めに出た目標が居座り続ける。負荷を下げるほどではないので、目標だけ動かす。

負荷を上げる手段は、**チューブなら色、自重なら種目の難易度**（壁 → ひざつき → 腕立て → 足上げ）。

### 持ち時間

1種目 ≒ 5分（3セット + 休憩 + 準備）。5分=1種目、10分=2、15分=3、20分=4。
部位のローテは動画と共通。**今日すでに記録があれば、その部位のまま続く。**

### 測る

初回に4種目（スクワット・腕立て・チューブ シーテッドロウ・プランク）を限界まで1セット。
その結果から全種目の出発点を決める。**正確に当てる必要はない。** 2〜3回やれば目標の上げ下げが
正しい位置へ寄せる。設定ではなくメニュータブの「測り直す」でやり直せる。

⚠️ **腹筋ローラーだけは、測定では膝コロまでしか上げない。** プランクが長いことと立ちコロが
できることは別で、立ちコロは一度試して腰を痛めると取り返しがつかない。上げるのは達成度に任せる。
すでに立ちコロが出てしまった端末は、`capRoller()` が起動時に一度だけ膝コロへ戻す。

### 一連の実行（タイマー）

**種目カードの「はじめる」**でその種目だけ（3セット）、**上の「全部」**でその日の種目を頭から流す。
構え5秒 → 1セット → 休み → … と進み、最後のセットで終わる。画面を触るのは最初の1回だけ
（`buildSession()` が手順の配列を作り、画面はそれを上から再生するだけ）。
今日すでに記録した種目は、どちらから始めても飛ばす。

| | 長さ |
|---|---|
| 構え | 5秒 |
| 回数の種目 | 目標回数 × 3秒（1回3秒。その間隔でピッと鳴る） |
| 秒の種目 | 目標秒そのまま |
| セット間の休み | 60秒（設定で変えられる） |
| 種目を変えるときの休み | 90秒（同上） |

**片脚・片腕でやる段階は、右と左を続けてやって1セット**（間に休みを挟まない）。
サイドプランクは段階に関係なく左右、ほかは負荷の名前に「片」が付くときだけ。
そのぶん時間は2倍かかるので、選んだ分数より長くなる。

**「一時停止」で止められる。** 休んでいる間は **＋15秒／−15秒** でその休みだけ伸び縮みする
（次のセットの休みは変わらない）。

種目カードの**「設定」**で、その種目だけ**目標・セット数・休み**を決められる（`rx[key]` の
`reps` `sets` `rest`）。決めていない種目は、3セットと全体の既定を使う。
目標を手で変えても、翌日からの自動調整はそのまま効く。

終わりの**「おつかれさま」で全セットが一覧になる**。`1セット目 右 8回` のように
左右も分けて並び、それぞれ ＋／− で直してから「おわり」で記録する。

残り3秒から予告音、0で長い音とバイブ。「ここまで」はそのセットを実測で打ち切る。

セットが終わるたびに、**その回数を ＋／− で直せる**（休んでいる間に直す。最後のセットは
「おわり」を押すまで待つ）。タイマーは鳴った数を数えているだけで体が動いたかは見ていないので、
放っておくと目標どおりできたことになる。ここで実際の数に直す。

**「やめる」は何も記録せずに閉じる。** 同じ実行で終えた種目も残らない（惜しければカードの
「記録」で手入力する）。

記録は**3セットのうち一番少なかった数**（全セット目標に届いて初めて目標が上がる形に
そろえるため）。**0 のセットは「飛ばした」とみなして数えない**（記録すると負荷が下がるため）。

⚠️ **残り秒は時刻の差から出している。** 数え上げる作りにすると、画面が消えている間にずれる。
⚠️ **マナーモードでは鳴らない。** バイブで補っているが、無音運用なら画面を見る必要がある。
⚠️ **アプリを閉じると途中復帰できない。** 実行中の状態は保存していない。

### 記録

メニューでやった分は動画と同じ `logs` に入る（`ex` に種目キー、`done` にできた回数）。
連続日数・部位のバランスにもそのまま数えられる。

記録には `prev`（押す前の負荷・目標・前回）を控えてある。設定の「今日の記録を消す」は
**処方もここまで戻す**。控えが無い古い記録は、負荷だけ戻して「前回」を消す。

押し間違えたときは、カードの**「取り消す」でその種目だけ**戻せる（記録を消し、処方も `prev` まで戻す）。

カードには**セットごと（左右ごと）の入力欄**が並ぶ。1セット終わるたびに入れていけばよく、
入れた数は `state.draft` に即座に残る（画面を閉じても消えない。日が変われば捨てる）。
「記録」を押すと、**タイマーのときと同じ確認画面**（`reviewEx()`）が開く。全セットが並ぶので
＋／− で直してから「おわり」で記録する（直した数は書きかけにも戻るので、「やめる」でも消えない）。
何も入れずに押したときも同じ画面が開き、**各セットは目標の数で並ぶ**（届かなかったセットだけ
− で下げればよい）。`v` が 0 のセットは記録に残らない。

記録には `sets`（`{set, side, v}` の配列）が入る。`done` は**一番少なかった数**で、
目標の上げ下げはこの値で決まる。

「測り直す」は処方を全部消すので、消す前の分を `rxBackup` に控える。測るフォームに
**「前の目標に戻す」**が出て、押せば元どおり。測り直して「決める」まで進むと控えは捨てる。

### お手本

21種目それぞれに、日本語でその種目だけを解説している動画を固定してある（`EXERCISES` の `ref`）。
頭から見れば足りるので、開始位置は付けていない。全部、公開中・埋め込み可を確かめた。

⚠️ **プルオーバーはケーブル版、ウッドチョップは器具が映像で確認できていない。** チューブで
その種目だけを解説した日本語の動画が見つからなかった。動きは同じなので、器具だけ読み替える。

## 動画について

YouTube「ザ・きんにくTV」の再生リスト「自宅で筋トレ」30本が土台。器具なしで10分前後のもの。

そこに26本を足して **56本**。きんにくTV は器具なしの都合で背中が1本・腕が1本しかなく、
同じ動画が繰り返されるため。足したのは次のとおり。

| 足したもの | 本数 | 出どころ |
|---|---|---|
| 背中（タオルを使う／器具なし） | 3 | CALISLIFE自重トレ |
| 腕 | 2 | CALISLIFE自重トレ |
| 腹筋ローラー | 3 | fis・Big Hide Channel・MELOS |
| ストレッチ（腰・お尻） | 3 | 前田のまいにちセルフケア・B-Flow |
| ストレッチ（肩甲骨・肩こり・腰） | 3 | オガトレ・前田のまいにちセルフケア・Marina Takewaki |
| **背中（チューブ）** | 4 | 前田のまいにちセルフケア・RIZAP公式・uFit・VRTX BAND |
| **上半身まとめて（チューブ）** | 1 | 前田のまいにちセルフケア |
| **ストレッチ 肩甲骨（チューブ）** | 1 | 前田のまいにちセルフケア |
| **ストレッチ 開脚** | 1 | オガトレ |
| **背中（ドアアンカーを使う）** | 3 | VRTX BAND・まえりゅうチャンネル |

**背中だけは器具に頼っている。** 自重では「引く」相手がいないので、負荷が作れない。
タオルは家にあるもので済ませていたが、等尺性（動かずに耐える）になって効かせにくいため、
2026-11-01 にトレーニングチューブ（ドアアンカー付き）を買い足した。
持っているのは **ハンドル・ドアアンカー・アンクルストラップ付きの5本セット**（TheFitLife）。
動画はこの形に合うものを選んでいる。ループバンド（輪になった布バンド）の動画は形が違う。

> [!warning] ゴムは消耗品
> 劣化すると使用中に破断してハンドルが顔に跳ねる。使う前に端まで伸ばして白い筋や傷を見る。
> **子どもの手が届く場所に置かない**（首に巻ける長さがある）。
> 「最大136kg」は5本すべてを束ねた合計値で、1本ずつは9〜18kg程度。

動画が削除された、分類がおかしいといった場合は、設定画面の「動画リスト」で
オン・オフと部位・レベルを直せる。

## 意見ボタン

使っていて気づいたことを、その場で送れる。後でチャットに「フィードバック見て」と言えば、
Claude が読んで直し、返事がアプリの一覧に出る。

- 送信時に「どの画面の、どの動画で」が自動で付く。本文に書かなくても伝わる
- 送り先は非公開リポジトリ `karada-log-feedback` の Issue
- 最初の1回だけ合言葉を入れる（端末の中にだけ残る）

仕組みと運用の手順は [CLAUDE.md](CLAUDE.md) にある。

## 開発メモ

素の HTML / CSS / JavaScript。ビルド不要。ライブラリも使っていない。

```
app/index.html             画面
app/app.js                 ロジックと動画リスト
app/style.css              配色(ダークモード対応)
app/sw.js                  オフライン動作
app/manifest.webmanifest   ホーム画面に追加するための設定
index.html                 旧URLから app/ への転送ページ
sw.js                      旧 Service Worker の後始末(自分で登録を解除する)
```

公開先は **https://karada-log-3ay.pages.dev/**(Cloudflare Pages)。
`main` に push すると自動でデプロイされる。

> [!important] GitHub Pages ではなく Cloudflare Pages で配信している
> もとは GitHub Pages(`fukushimak1207.github.io/karada-log/`)に置いていたが、
> Android の Chrome が「このアプリはすでにインストールされています」と言ったまま
> ホーム画面に追加できなかった。原因は**同じオリジンに複数の PWA を置いていたこと**。
> web.dev は独立した PWA を別オリジンに置くことを強く推奨している。
>
> manifest の id 変更・PNG アイコン・Service Worker のキャッシュ修正・同一オリジン内での
> URL 変更はどれも効かず、**別オリジンに移して解決した**。
>
> リポジトリの `app/` が Cloudflare Pages の公開ディレクトリ。
> GitHub Pages 側は転送ページとして残してあり、旧URLを開くと新URLへ飛ぶ
> (記録はオリジンごとに別なので、両方で使うとデータが2か所に分かれるため)。

**ファイルを更新したら `sw.js` の `CACHE_VERSION` を上げること。**
上げないとスマホが古いキャッシュを使い続ける。

ロジックの検証は Node で行う（日付計算・ローテーション・レベル上げ・連続日数）。
`localStorage` と `document` をダミーに差し替えて `app.js` を読み込む方式。
